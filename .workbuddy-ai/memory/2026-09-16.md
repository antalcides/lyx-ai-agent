## Diagnóstico: por qué no conectaba con la nube

Probado con las clases reales de `app/providers` (chat de 1 token, no solo `/models`):

| Proveedor | Antes | Causa | Ahora |
|---|---|---|---|
| OmniRoute | 502 ProxyError | `base_url` apuntaba a `https://api.omniroute.ai/v1` (host muerto). El gateway real es local: `http://localhost:20128/v1` | OK |
| OpenRouter | 401 Missing Auth | La clave guardada tenía el prefijo literal `api-key: ` | OK |
| Gemini | 404 modelo retirado | `gemini-2.0-flash` ya no existe; listas de respaldo obsoletas | OK |
| Ollama | — | funcionaba | OK |
| OpenAI | 401 | La clave `HCZbGDT3...` no es válida (no empieza por `sk-`) | requiere clave nueva |
| Anthropic | 400 | Clave válida pero **sin saldo** | requiere recarga |

apuntando a un host de nube inexistente → 502 en cada envío.
